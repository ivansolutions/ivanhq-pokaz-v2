      Bots und AssistentenNehmen Bestellungen an und beantworten die üblichen Fragen.
      
Bots in Telegram, Slack, Microsoft Teams, WhatsApp oder Discord: Sie nehmen Bestellungen an, beantworten die üblichen Fragen und geben den Rest an einen Menschen weiter — mit Protokoll, wer wann übernommen hat. Sie laufen auf n8n, einer Plattform, die Sie auf Ihrem eigenen Server betreiben können.
  • Ein Bot in Ihrem Kanal — und er sagt, dass er ein Bot ist
  • Antworten, die Sie selbst ändern
  • Übergabe an einen Menschen, protokolliert

    

      Systeme verbindenEinmal eintippen — überall da, wo es gebraucht wird.
      
Shop, CRM, E-Mail, Tabellen, Zahlungen, Messenger — so verbunden, dass ein Eintrag einmal eingegeben wird und überall erscheint, wo er gebraucht wird. Der wiederkehrende Teil läuft auf n8n: Die Verbindung ist ganz sichtbar und lässt sich an jemand anderen übergeben.
  • Eine Verbindung, die man ganz sieht
  • Einmal eingeben statt dreimal
  • Protokoll für jeden Eintrag

    

      KI-Agenten mit NotbremseDer Agent fragt, Sie antworten mit einem Knopf.
      
Die Grenze ist beweglich, und Sie verschieben sie. Es geht nicht um das Versprechen, dass der Agent etwas »nicht tut«: Ohne Ihre Bestätigung hat er schlicht keine Rechte für eine Mail an Kunden, eine Zahlung oder eine Änderung im CRM — so sind die Schlüssel vergeben. Er fragt, Sie antworten mit einem Knopf dort, wo Sie ohnehin sind: Telegram, Slack oder Microsoft Teams. Ein Schritt, der sich an Ihren eigenen Daten immer wieder bewährt hat, darf allein laufen. Läuft etwas auseinander, kommt die Notbremse zurück.
  • Ein Agent für Ihre Aufgaben
  • Liste der Schritte: wo er fragt, wo er allein geht
  • Bestätigungs-Knopf vor jedem solchen Schritt

    

      Wächter und BerichteWenn um vier Uhr morgens etwas bricht, erfahren Sie es von mir.
      
Der Wächter prüft rund um die Uhr eine gemeinsam abgestimmte Liste. Bricht um vier Uhr morgens etwas, erfahren Sie es von mir und nicht vom Kunden — in Telegram, Slack oder Microsoft Teams. Was nicht auf der Liste steht, sehen Sie vorher: Sie wird mit Ihnen erstellt und liegt bei Ihnen. Dazu einmal pro Woche ein kurzer Bericht.
  • Meldung, wenn etwas bricht
  • Wochenbericht in normalen Worten
  • Verlauf von Ausfällen und Reparaturen

    

      Anrufe mit KI-Stimme in Vorbereitung — noch nicht im AngebotDie Stimme sagt im ersten Satz, dass sie eine Maschine ist.
      
Die Stimme sagt im ersten Satz, dass sie eine Maschine ist, und fragt, ob das Gespräch aufgezeichnet werden darf — ohne Erlaubnis keine Aufzeichnung und keine Auswertung. Sie nimmt Anrufe an, beantwortet übliche Fragen, nimmt die Anfrage auf und gibt an einen Menschen weiter, was ein Mensch entscheiden muss. Sie ruft auch selbst an — aber nur bei Menschen, die zugestimmt haben.
  • Eingehende Anrufe · Rückrufe nur nach Zustimmung
  • Gesprächstext — mit Erlaubnis
  • Anfrage direkt in Ihr System

Was ich nicht verspreche.

    
  • Kein »KI ersetzt Menschen«.
    Die Automatisierung übernimmt das Wiederkehrende. Entscheidungen bleiben bei Menschen — und ich schreibe auf, wo die Maschine anhält.
  • Keine Zauberei ohne Zugang.
    Hat das System keinen Zugang, gibt es dort nichts zu automatisieren. Das sage ich vor der Zahlung, nicht danach.
  • Keine Blackbox.
    Code, Konten und Schlüssel gehören Ihnen. Sie können sie an jemand anderen übergeben, und die Arbeit geht ohne mich weiter.
  • Kein »die Daten liegen bei mir«.
    Wo Ihre Daten liegen, entscheiden Sie: auf Ihrem Rechner, auf Ihrem Server oder auf einem Server in dem Land, in dem sie liegen sollen.

    
Auch ein Kanal ist ein Ort, an dem Daten liegen — die Wahl des Kanals ist die Wahl eines Landes. Sie wollen in der EU bleiben? Dann baue ich den Kanal dort: eigener Chat oder E-Mail, auf Ihrem Server oder meinem. Sie wollen Telegram, Slack oder Microsoft Teams, weil Ihr Team schon dort ist? Das ist eine normale Wahl. Wohin die Daten dabei gehen, sage ich vor Beginn der Arbeit.
